# Design Release Checklist

## Brand

- approved logo master used
- correct theme lockup
- no re-typeset wordmark
- no unapproved glow, shadow, or recolor

## UI

- semantic tokens only
- state names consistent
- loading, stale, offline, and error handled
- no color-only meaning
- touch targets meet 48dp
- dark and light themes reviewed

## Commands

- pending state
- duplicate submission blocked
- hardware acknowledgement distinguished from cloud acceptance
- timeout and rejection reason
- audit timestamp

## Alarms

- priority assigned
- cause, consequence, and action
- acknowledgement separate from clearance
- no continuous flashing
- stale data cannot appear live

## Accessibility

- TalkBack
- keyboard / D-pad
- 200% font scale
- reduced motion
- contrast
- grayscale and color-vision review
