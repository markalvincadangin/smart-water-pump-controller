## Release v1.0.0 (Initial deployment-ready release)

This folder is the **release documentation set** for the first deployment-ready snapshot of the Smart Water Pump Controller.

It is intended to be detailed enough for:

- Operators deploying the system end-to-end
- Engineers maintaining firmware, dashboard, functions, and Firebase rules
- Auditors validating safety, control, and data contracts

### Documents

- **Release notes**: `release-notes.md`
- **System overview**: `system-overview.md`
- **Deployment guide**: `deploy.md`
- **Firmware documentation**: `firmware.md`
- **Dashboard documentation**: `dashboard.md`
- **RTDB contract (schema + ownership)**: `rtdb-contract.md`
- **Dashboard UX spec**: `dashboard-ux-spec.md`

### Source of truth vs release snapshot

- **Current specs** live under `docs/specs/` and may evolve after this release.
- This `docs/releases/v1.0.0/` set describes the system behavior and contracts **as implemented in this repository at the time of release**.
