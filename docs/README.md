# Documentation Index

This directory contains all project documentation for the Smart Water Pump Controller.

- **Releases** (`./releases/`)
  - `v2.0/` — current stable firmware/RTDB and dashboard v2 specs: [system-overview.md](./releases/v2.0/system-overview.md), [firmware-documentation.md](./releases/v2.0/firmware-documentation.md), [dashboard-documentation.md](./releases/v2.0/dashboard-documentation.md), [firmware-rtdb-spec.md](./releases/v2.0/firmware-rtdb-spec.md), [dashboard-ux-spec.md](./releases/v2.0/dashboard-ux-spec.md), [deploy.md](./releases/v2.0/deploy.md) (canonical deployment guide).
  - `v3.0/` — firmware v3 behavior and migration notes (when running v3 firmware).
- **Operations** (`./operations/`)
  - [troubleshooting.md](./operations/troubleshooting.md), [safety.md](./operations/safety.md), [NOTIFICATIONS_SETUP.md](./operations/NOTIFICATIONS_SETUP.md), [FIRMWARE_CONFIG_FROM_DATABASE.md](./operations/FIRMWARE_CONFIG_FROM_DATABASE.md), [RS485_TANK_LINK.md](./operations/RS485_TANK_LINK.md).
- **Assets** (`./assets/`)
  - `diagrams/` — system diagrams (e.g. Diagram.png, Diagram.pdf).
  - `manuals/` — Master_Manual.pdf, Hardware_Documentation.pdf, Software_Firmware_Documentation.pdf.
- **Archive** (`./archive/`)
  - Superseded docs (DEPLOY_GUIDE, DASHBOARD_DESIGN_v2, FIRMWARE_DASHBOARD_DESIGN_v2, ENHANCEMENT_PLAN) kept for reference only.

Authoritative specs for each version live under `./releases/<version>/`. See the
project root `README.md` for which version is currently deployed in production.
