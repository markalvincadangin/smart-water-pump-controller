# SmartFlow Specifications (Current)

This folder contains the current, non-versioned specifications for SmartFlow as implemented in this repository.

## Specification Set

- `firmware.md`: ESP32 + ESP8266 firmware architecture, safety model, mode logic, and RTDB contract.
- `firmware_operational_rules.md`: normative firmware behavior rules and command semantics.
- `dashboard.md`: dashboard system behavior, control semantics, and operator-facing UX contract.
- `rs485_protocol.md`: authoritative RS-485 transport and payload protocol contract.

## Document Governance

- Historical and superseded documentation is stored in `docs/archive/`.
- Stable release snapshots are stored in `docs/releases/`.
- The first stable release package is `docs/releases/v1.0.0/`.
