Pre-flash blockers — master node

These 3 items require a decision or action before flashing the master.
#ItemAction needed
1BLOCKER RTDB control node has emergency_stop: true and countdown_stop: true stuck highClear these in Firebase Console before boot. On first poll the firmware will latch the e-stop and self-clear countdown_stop, but with emergency_stop: true the pump will be locked out immediately. Set both to false before flashing.
2BLOCKER RTDB control node has bypass_flow_sensor: true and bypass_level_sensor: true stuckBoth bypasses are latched ON from testing sessions. With both bypasses active, dry-run protection and level-based stop are disabled on first boot. Set both to false in Firebase before flashing.
3DECISION RTDB control mode: "AUTO" but last audit entry shows mode cycling through COUNTDOWN/MANUAL/FORCE_OFF/FORCE_ON repeatedly during testingConfirm the intended startup mode. "AUTO" is the safe choice. The NVS will restore whatever was last persisted, so the Firebase mode field will be applied on the next poll cycle. Make sure Firebase and intended NVS state agree.
