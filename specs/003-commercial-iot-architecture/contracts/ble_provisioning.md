# BLE Provisioning Contract

This document defines the BLE GATT services and characteristics used for the headless provisioning flow of the SmartFlow device.

## Service

- **UUID**: `4fafc201-1fb5-459e-8fcc-c5c9c331914b`
- **Name**: SmartFlow Provisioning Service

## Characteristics

| Name | UUID | Permissions | Description |
|------|------|-------------|-------------|
| **SSID** | `beb5483e-36e1-4688-b7f5-ea07361b26a8` | WRITE | Wi-Fi network SSID |
| **Password** | `beb5483e-36e1-4688-b7f5-ea07361b26a9` | WRITE | Wi-Fi network password |
| **Claim Token** | `beb5483e-36e1-4688-b7f5-ea07361b26aa` | READ / WRITE | Cryptographic token for device ownership claiming. Generated by firmware on first boot (READ), or injectable by app (WRITE). |
| **Commit** | `beb5483e-36e1-4688-b7f5-ea07361b26ab` | WRITE | Write `1` or `commit` to finalize provisioning and restart in ONLINE mode |

## Flow

1. Device boots and advertises as `SmartFlow-<Last 6 of MAC>`.
2. App connects and reads **Claim Token** (to associate device in Firebase).
3. App writes **SSID** and **Password**.
4. App writes `1` to **Commit**.
5. Device verifies data, saves to NVS, stops BLE, connects to Wi-Fi, and transitions to ONLINE.
